      권한 요청

      수락하면 그 이름과 비밀번호로 로그인할 수 있습니다. 거절하면 요청이 지워집니다.

      계정 목록

      차단하면 로그인 중이어도 다음 새로고침 때 접속이 끊깁니다. 같은 내용이 구글 시트 "계정" 탭에 저장됩니다.

      데이터 관리

      데이터 최신화 (구글 시트 열기)
      1. ERP에서 일별 판매현황 엑셀을 2022.01.01부터 전체 기간으로 내려받습니다.
      2. 구글 시트의 "판매데이터" 탭에서 파일 → 가져오기 → 업로드 → "현재 시트 바꾸기"로 덮어씁니다.
      3. 시트 메뉴 대시보드 → 반영하기를 누릅니다. 매핑에 없던 품목·거래처가 있으면 매핑 탭에서 분류를 고르고 한 번 더 반영합니다.
      4. 이 화면에서 "반영된 데이터 다시 불러오기"를 누릅니다.

      주간 요약 메일

      매출·수량, 전주 대비, 4주 평균 대비, 상위 거래처 5곳, 상위 품목 5개를 메일로 보냅니다.

      접속 기록

      최근 기록부터 최대 1,000건. 같은 내용이 구글 시트 "접속기록" 탭에도 쌓입니다.
